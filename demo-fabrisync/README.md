# FabriSync OP Control — Demonstração

Demo interativa do controle de Ordens de Produção (OPs) para fábricas de esquadrias de alumínio e vidro.

- Arquivo único, funciona offline, sem login.
- Todos os dados são fictícios (obras, clientes e pessoas de exemplo).
- Abra o `index.html` no navegador ou acesse o link público da demonstração.
